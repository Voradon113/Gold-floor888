📊 ปุ่ม “ดึงวอลุ่มออปชั่น”

ติดตั้งครั้งเดียว ใช้ได้ตลอด · ปุ่มนี้ดึงข้อมูลจาก TradingView เท่านั้น ไม่ส่งไปที่อื่น

1กด Ctrl + Shift + B ให้แถบบุ๊กมาร์กโผล่ใต้ช่องที่อยู่เว็บ
2ลากปุ่มเขียวข้างล่าง ขึ้นไปปล่อยบนแถบบุ๊กมาร์ก (อย่าคลิก ให้กดค้างแล้วลาก)
📊 ดึงวอลุ่มออปชั่น
3ไปหน้าชาร์ต TradingView → คลิกปุ่ม 📊 ดึงวอลุ่มออปชั่น บนแถบบุ๊กมาร์ก → รอแถบเขียว “คัดลอกแล้ว ✓” ขึ้นกลางจอ
4ดับเบิลคลิกอินดิเคเตอร์ OptVol บนชาร์ต → คลิกในกล่องข้อความใหญ่ → Ctrl + A แล้ว Ctrl + V → Ok

อยากได้ข้อมูลใหม่ระหว่างวัน → ทำข้อ 3–4 ซ้ำ (กดปุ่ม แล้ววางทับของเดิม)

ถ้าขึ้นแถบแดง “ข้อมูลเก่า” แปลว่า TradingView ส่งข้อมูลรุ่นเก่ามา รอสักครู่แล้วกดใหม่
